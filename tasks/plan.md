# План сборки: «Подход»

Спецификация: `X:\SALE TOOLS\MY_BRAIN\health\app\SPEC.md` · решения по дизайну: `RESEARCH.md` там же.
Статус: **черновик плана, ждёт одобрения** (2026-11-14). Кода нет.

## Суть
iPhone PWA для записи тренировок по системе Максима: запись в зале, прогресс, советы правилами, разбор недели копированием в чат. Данные на телефоне, офлайн, без сервера.

## Архитектурные решения
- **Vite + React + TypeScript + vite-plugin-pwa** — самый обкатанный путь к PWA, которую можно ставить на экран «Домой».
- **IndexedDB через Dexie** — данные на телефоне, работает без интернета, сервер не нужен.
- **Вся логика советов — чистые функции в `src/logic/`**, покрыты тестами Vitest. Экран только показывает результат.
- **Графики — свой SVG**: линия и полоски, библиотека не нужна.
- **Выкладка проверяется в самом начале** (задача 1): главный риск — поведение PWA на iPhone, его надо поймать до того, как написан весь интерфейс.

## Порядок
Срезы сделаны «по вертикали»: после каждой задачи приложение работает и его можно открыть.

### Этап 1 — основа
- [ ] **1. Каркас + выкладка.** Проект, цвета «Вечер», шрифты Unbounded/Montserrat, нижняя панель на 4 вкладки (пустые экраны), иконка «Подход». Выложить, поставить на iPhone.
- [ ] **2. Данные + твои шаблоны.** Схема базы (упражнения, шаблоны, тренировки, подходы, замеры, InBody). Шаблоны A и Б и ротация заполняются из `training-plan.md`: мышцы, группы, схемы, RIR, шаг веса, суперсеты, заметки к технике.
- [ ] **3. Логика советов.** e1RM, следующий вес, рекорды, плато (4 недели), объём на группу (10 подходов) + тесты на твоих реальных цифрах.

**Проверка 1:** иконка на айфоне открывается без интернета, тесты логики проходят, шаблоны A/Б на месте.

### Этап 2 — запись тренировки (главное)
- [ ] **4. Экран тренировки.** Сегодняшняя по ротации (или выбрать другую), всё списком, текущее раскрыто, заметка к технике, строки подходов `№ · было · кг · повт · RIR · ✓`, серые прошлые цифры, правка тапом, сохранение.
- [ ] **5. Таймер + подсказки.** «Начать / Закончить тренировку», время во вкладке; подсказка «в следующий раз +2.5» и рекорды прямо в упражнении.
- [ ] **6. Перенос истории.** Скрипт разбирает `health/logs/*.md` с июля → файл → импорт в приложение. Проверяем выборочно с тобой.

**Проверка 2 — в зале:** ты проводишь одну настоящую тренировку только в приложении. Всё, что неудобно, правим до следующего этапа.

### Этап 3 — анализ
- [ ] **7. Прогресс.** Сводка недели + список с мини-графиками; подробный экран упражнения с графиком и периодами.
- [ ] **8. Тело.** 4 плитки, замеры, новый замер, InBody.
- [ ] **9. История.** Недели, раскрытие, «Скопировать неделю» в формате для разбора.

**Проверка 3:** скопированную неделю вставляешь мне — я делаю разбор без уточняющих вопросов.

### Этап 4 — настройка и сохранность
- [ ] **10. Редактор шаблонов.** Список, ротация, порядок перетаскиванием, суперсеты, настройки упражнения, замена/удаление с сохранением истории.
- [ ] **11. Резервная копия.** Экспорт всех данных в файл и импорт обратно.

**Финальная проверка:** все критерии готовности из спецификации.

## Риски
| Риск | Насколько серьёзно | Что делаем |
|---|---|---|
| PWA на iPhone ведёт себя не так (офлайн, установка, клавиатура) | высоко | выкладка и установка — задача 1 |
| Данные только на телефоне | высоко | экспорт в файл (задача 11), напоминание раз в неделю |
| Старые логи в разном формате | средне | импорт разово, сверка с тобой по выборке |
| Цифровая клавиатура iOS без запятой/точки для 52.5 | средне | проверяем в задаче 4, при необходимости своё поле ввода |

## Открытые вопросы
1. **Хостинг и видимость кода.** GitHub Pages бесплатно работает только с публичным репозиторием: виден код, но не твои данные (они на телефоне). Если код хочешь скрыть — Cloudflare Pages, тоже бесплатно, с приватным репозиторием.
